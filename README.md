# Task 2: Data Visualization and Storytelling

## Objective

The objective of this task was to create meaningful visualizations and communicate business insights using sales data.

## Dataset

The Superstore dataset was used for this task.

## Tool Used

* Tableau Public

## Visualizations Created

1. Total Sales KPI
2. Sales by Category
3. Sales by Region
4. Sales Trend Over Time
5. Sales by Sub-Category

## Dashboard

The visualizations were combined into an interactive sales dashboard with filters and key business insights.

## Key Insights

* Sales performance varies across different categories and regions.
* Some product sub-categories contribute significantly more to total sales.
* The sales trend shows changes in performance over time.
* The dashboard helps identify important sales patterns and business opportunities.

## Files

* `Superstore.xlsx` – Dataset used for analysis
* `Dashboard.png` – Dashboard screenshot

## Outcome

This task helped in understanding data visualization, dashboard design, chart selection, and visual storytelling.

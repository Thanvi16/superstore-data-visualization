# Superstore Data Visualization

## Project Overview
This project focuses on analyzing Superstore sales data using data visualization techniques.

## Objective
To create meaningful visualizations that help understand sales, profit, customers, products, and regional performance.

## Dataset
Superstore Sales Dataset

## Tools Used
- Tableau
- Microsoft Excel
- GitHub

## Visualizations
- Sales by Category
- Profit by Region
- Sales by Segment
- Monthly Sales Trend
- Top Products
- Sales and Profit Analysis

## Outcome
The dashboard provides useful insights into sales and profit patterns and helps in making data-driven decisions.
